We are building an open-source community health system for frontline health workers in the Northern,
Savannah and North East regions. It runs offline on phones, works with the Ghana Health Service's
reporting system (DHIMS-2), and is designed to be owned and run by Ghanaian institutions over time.

We would like to host a small production environment in Ghana from [month year] for a pilot in one
district. We are asking for a quotation for the following, for 12 months:

1. Virtual machine or container hosting, about 2 vCPU and 4 GB RAM to start, scalable.
2. Managed or self-managed PostgreSQL, about 20 GB, with daily encrypted backups kept in Ghana.
3. Object storage for backups, about 100 GB, in Ghana.
4. Network egress for about 50 concurrent users.
5. Support hours and an uptime commitment.
6. Whether a not-for-profit or public-health rate applies.

Our requirements, which we would like confirmed in the quotation:
- All health data stored and processed in Ghana, as Act 843 requires for sensitive data, and as the
  Data Protection Bill 2025 proposes to require.
- Data encrypted at rest and in transit.
- The right to export or delete all data on request.
- The Ghana Health Service's own ownership and control of data as a long-term option.

We would welcome a short call to discuss hosting for a government-aligned health project. Please send
the quotation, the terms and any onboarding steps.
